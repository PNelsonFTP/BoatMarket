## Owner-controlled integration choices

The existing 30-minute worker interval is preserved. Daily is `WORKER_INTERVAL_MINUTES=1440`; weekly is `10080`. The machine must run the worker and remain available. No seller messages, email/webhook channels, new OS service, public geocoder permission or public Pages deployment were enabled by this implementation.

The first-party project remains private and `UNLICENSED`. An open-source licensing choice, credentials for an external routing/geocoding provider, permissioned dealer feeds, and a public publication decision cannot be inferred from a code change. Their supporting configuration, review tools and diagnostics are delivered.
