# BoatScout implementation decisions

1. **The original implementation was delivered under the owner’s build authorization.** BoatPrompt.md preserves that brief. Later requests control the scope of follow-up work; the October 20 review authorized documentation and cleanup recommendations with deletion prohibited before approval. The owner subsequently approved the high-confidence group only; that cleanup is complete and all other groups remain pending.
2. **Keep Next.js 15, export the frontend, split the API.** GitHub Pages cannot execute Next route handlers or background jobs. Next App Router exports the website; Fastify hosts the authenticated Node API. Both use the same typed filter engine. The backend can also serve the exported website.
3. **SQLite with Prisma is the default.** It gives a durable relational model and a one-command local setup. PostgreSQL/PostGIS and Redis would add services before there is a scale requirement. Haversine distance implements radius search. A PostgreSQL migration is future work, not an advertised alternate mode.
4. **Simple periodic Node worker.** A worker process performs collection followed by alert evaluation. Database leases prevent duplicate collector/alert runs across app/worker processes. This avoids Redis/BullMQ for a single user. The default 30-minute interval after each completed cycle is configurable from 1 to 10,080 minutes. Collector/pipeline leases renew via heartbeat, propagate cancellation and fence listing writes; alert delivery now also renews and fences its lease with per-channel delivery history. Opt-in daemon auto-export uses the same protected refresh pipeline.
5. **Static sites get useful data modes.** Sample, published snapshot, and connected data are separate and visible. Browser storage is used only for standalone personal state and preferences. Connected state is in SQLite. Authentication sessions are held in sessionStorage and expire in 12 hours; passwords are not persisted by the frontend.
6. **Rich specifications in a catalog and validated JSON.** All requested filter attributes exist in lib/catalog.ts. Essential columns, engines, sellers and price history remain relational. Less common specs live in the canonical JSON payload, avoiding a huge nullable migration while preserving typed values and an extensible filter UI. The SearchArea model is available for reusable source-area records; per-search areas are currently stored inside SavedSearch.filters.
7. **Conservative normalization and deduplication.** Core metadata is extracted when available. Heuristic make/model/year results include confidence, and unknown specs remain unknown. Automatic grouping uses indexed, structurally valid modern HINs independent of source/model spelling. Different valid HINs and reviewed different-vessel decisions veto transitive grouping. Photo/spec similarities rank review suggestions, including same-source reposts. Same/different/undo decisions preserve original ads and personal state; bounded optional perceptual evidence ranks review suggestions and never auto-merges alone. See FUTURE_IMPROVEMENTS.md.
8. **Configured regional inventory with visible coverage limits.** Twelve enabled sources have dedicated collection paths: regional Craigslist, OnlyInboards, Bass Boat Central, and nine dealer inventories. Their dated permitted-access results and current failures are recorded separately; an implemented adapter does not establish present access. Supported sites follow same-origin pagination with explicit page/detail caps. A repeated source ID is processed once per run so alternate page links cannot overwrite enriched details or inflate counts. Other marketplaces retain structured-data/selector fallbacks without a claim of live compatibility. Search-area filters are local and do not rewrite remote marketplace queries. [SOURCE_COVERAGE.md](SOURCE_COVERAGE.md) records included regions and gaps.
9. **Facebook is import-assisted.** This build accepts user-exported canonical records, not cookies or authenticated browser session harvesting. This protects reliability and avoids building an access-bypass dependency into the product. Other optional Playwright rendering is same-origin and checks robots first.
10. **Keep observed history on failures.** Empty/challenged pages are errors, not proof of removal. Unseen real listings become stale after 14 days; explicit source status can mark sold/removed. A source failure does not break other sources.
11. **Single-user auth, structurally separable users.** Workspace tables use user IDs. Today every session maps to the local user; multi-user auth needs a real identity provider/session store and ownership checks before exposing the app to several users.
12. **Lake Holiday screening with explicit provenance.** The user selected Lake Holiday, IL as home. The official publicly linked December 2, 2025 rulebook, reviewed September 8, 2026, informs an editable inclusive-21.0-ft hulled-boat screen, with a warning about molded platforms, motor ratings, prohibited wakesurfing and use of wake-enhancing devices. Missing lengths fail this screen. Presets prioritize distance within 150 miles, offer fishing boats with reported 200+ hp and premium ski makes, and allow expansion to 250 miles. The main preset also screens out reported lengths below 18 ft. Separate broader views include unreported lengths or all nearby ads without a lake screen. A coverage panel explains the difference between the inventory pool and filtered matches. A model name or advertised nominal length does not establish registration eligibility.
13. **Observed market data only.** Charts use the current matches, deduplicated. They show asking prices and time tracked, not sales valuations or a complete historical market. Alerts compare saved-search matching state, baseline once, and enqueue durable changes.
14. **Licensed sample imagery.** Five local photographs represent broad boat categories. All seed listings and photos are labeled illustrative, source links point to example.com, and photo credits/licenses are bundled. No sample is presented as a verified live offering.
15. **Native HTML and accessible Radix composition.** Tailwind is available for utilities; a custom token-driven stylesheet supplies the nautical working-surface design. Native selects and checkboxes provide predictable keyboard behavior. Modal focus management uses Radix, following the shadcn composition pattern.
16. **GitHub Pages publication is a reviewed manual step.** The supplied directory originally had no Git repository. PNelsonFTP/BoatMarket became public at the owner’s authorization September 10 and the reviewed site is deployed; the latest recorded inventory release is October 19. Pages requires an approved exact review hash and BOATSCOUT_ENABLE_PAGES, followed by manual workflow dispatch. A source push does not publish, collect data or host the backend. No Sites cloud project or unrelated hosting target was created.
17. **Patched dependencies without an unnecessary framework migration.** Retain the prompt’s Next.js 15 line, upgrade Fastify static serving and Nodemailer, and pin compatible patched PostCSS/deepmerge-ts transitive dependencies. The September 8 runtime npm advisory check reported no vulnerabilities; that dated result is not a current advisory guarantee. See SBOM.md before interpreting its scope. Development and production build directories are separate so a static export can be built while the preview runs.

18. **Geographic precision is visible.** Public listing cities are geocoded once into a local cache; explicit refresh can geocode newly discovered cities; daemon geocoding is opt-in. City/state/ZIP ranking retains ambiguous candidates, and reviewed city-center corrections keep local evidence. Distances are approximate straight-line miles. Ambiguous unresolved locations stay unknown. A boat explicitly stored off site is excluded from the default location screen until its actual location is known.
19. **Cached pages are observations, not new checks.** Cached collections use the saved page observation time. A recent local cache is read before network throttling; new outgoing page requests still require robots checks and crawl delays. Raw HTML is cached locally, with source references and normalized payloads retained per record. Evidence objects and backup/research copies may legitimately retain the same bytes for different purposes. Before replacement, captured bodies are preserved as immutable SHA-256 objects with dated observation records. Conflicting power and implausible length fields remain unknown with an explanation.
20. **Document the delivered state and inventory scope.** README, OPERATIONS, HANDOFF, SOURCE_COVERAGE, LIVE_DATA, VALIDATION, CHANGELOG, and FUTURE_IMPROVEMENTS separate implemented behavior, observed results, and proposed work. SBOM.md explains reproducible CycloneDX inventories, the complete lock-entry inventory, dependency audit dates, and verified bundled-package evidence with full schema validation. A separate complete all-platform output covers npm’s own full-command limitation. No installed daily/weekly automation is implied; approved public deployments are recorded separately in LIVE_DATA.md and VALIDATION.md. CLEANUP_REVIEW.md records filesystem ownership, retention limits and unresolved cleanup candidates.

21. **Transactional boundaries are explicit.** Whole import files are previewed; connected imports are row/byte-bounded chunks with per-record accepted/error/uncertain manifests. They are not globally atomic. Workspace restores merge by default, preserve current edits, require explicit replacement review and use optimistic revisions. Storage is scoped to deployment, mode and backend, with deliberate legacy migration.
22. **Refresh protects the last reviewed website.** Full refresh creates a consistent verified SQLite backup, records outcomes, optionally enriches cities and atomically exports only successful results unless partial export is explicit. Cache age and page/detail caps remain visible. Price/status precedence uses observation age so older detail caches cannot undo fresher summary changes. Publication and scheduling are separate operator choices.
23. **Buying packets separate reported facts from verification.** Downloadable comparison HTML escapes source content, uses no scripts, excludes private notes and includes blank seller/inspection checklists. It does not assert availability, lake approval or mechanical condition.

24. **Permanent vessel identity with ad-level personal state.** Anchor retention and merge aliases preserve long-lived vessel links; split/undo keeps original ad IDs, private notes and source observations intact. Known examples are adjudicated from recorded evidence, with conflicting-HIN vetoes.
25. **Privacy belongs at every publication boundary.** Actual-location overrides, route origins and review evidence are private. Export restores source points. Exact-hash release review binds source, snapshot and SBOMs; Pages is a separate manual action.
26. **Bounded source coverage rather than unbounded crawling.** Detail rotation/checkpoints and summary-only policy are explicit. Staged source quality gates reject regressions before writes; historical evidence and reviewed reparse support parser repair.
27. **Protected storage and recoverable operation.** Retention requires a reviewed plan and fresh protection checks; restore writes only to a new directory. Singleton service identity and renewable leases prevent unrelated workers from being treated as this project.
28. **Deliberate runtime packaging.** Prisma CLI and Playwright JavaScript are explicit runtime dependencies; frontend/build dependencies are excluded from the backend image. Chromium binaries are present only in the optional rendered image. Pin images/actions and regenerate image-specific OS/native/browser inventories.
